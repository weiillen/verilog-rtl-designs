# Source Preservation Policy

The purpose of this repository is to present the uploaded work clearly without rewriting it.

## Preserved artifacts

The two PDF reports under each project's `original/` directory were copied directly from the uploaded archive. Their file contents were not edited, redacted, recompressed, or regenerated.

The cleaned filenames and folder paths are portfolio organization only. `ORIGINAL_FILE_MANIFEST.tsv` records the original archive path, portfolio path, file size, and SHA-256 checksum.

## Added artifacts

The following files were added around the original work:

- Markdown documentation;
- cropped PNG previews of simulation screenshots already present in the reports;
- the checksum manifest;
- verification and scope notes; and
- `.gitignore`.

No standalone Verilog source was reconstructed from the PDF listings.
